Share with your agents

Tell each Claude Code session what your other agents did hereWhen a Claude session starts in a project, it gets a short note about the other agents that worked there in the last 2 hours: what they changed, whether their tests pass, and whether they’re still at it. Later prompts only get a note when there’s news. dotpals doesn’t send it anywhere itself, but it becomes part of Claude’s context, which Claude Code sends to the model like the rest of your conversation (you won’t see it in the chat). Codex can’t receive notes.

Two agents, one file

When an agent is about to change a file another agent just changedAnother session changed it a few minutes ago and is still at it: that’s how parallel agents undo each other’s work. Claude Code can be stopped before the edit: Ask me first shows Claude’s permission prompt with the reason (“Codex (api) changed billing.ts 2 minutes ago. Edit anyway?”); Tell Claude stops the edit and tells Claude to re-read the file first. Other agents (Codex, Cursor, Gemini…) can’t be stopped: the notch and the pal tell you right after.
“Just changed” means withinOlder changes, and sessions that have gone quiet, don’t count.

Double-check unclear test results

dotpals reads each test run’s output for its summary (“48 passed”, “1 failed”). When it can’t tell, say no tests ran or the exit code disagrees with the output, it says Tests unclear. A checker can look at those runs once and decide. Clear results are never sent.
