Welcome to dotpals

dotpals watches your coding agents and checks their work: which files changed, which commands ran, and whether the tests really passed.

Next: connect your agents and test them. It takes about a minute.

Connect your agents

These are on this computer. Connect each one, then press Test: a pal says hello at the top of your screen, so you know it works.

You’re all set

  • The notch at the top of your screen shows what your agents are doing, as they do it.
  • The dashboard has the whole story: every file changed, command run and test result.
  • dotpals opens when you log in. Its menu is the dotpals icon in the menu bar; Set up agents… there brings this guide back.
  • Another agent? Anything can post to http://127.0.0.1:5175/event. The dashboard’s Agents page has examples.
